# 資源班字詞單產生器

幫資源班老師把某一冊國語的生字做成字詞單（.docx）。每課一個檔，每頁 6 個生字，版面和老師原本手做的五上字詞單一樣：

- 標題欄：`字詞【第N課 課名】｜【目標】生字/部首/部件/造詞｜生字列（靠左）`
- 每個生字：雄筆順「跟著顏色分部件」彩色字、注音格、部首/部件拆解、結構勾選、課本的詞+造詞格
- 最後一頁是花朵裝飾頁（範本內建）

**適用範圍：三到六年級**，任何出版社（康軒、南一、翰林）。老師已確認這個版面 3–6 年級都能直接用。**一、二年級不要直接套用**：低年級的部首/部件/結構/造詞欄位可能不適合，先跟老師討論要怎麼簡化版面再做。

**生字來源優先順序**：老師給的出版社/官方生字表（.doc、.docx、PDF、照片都可能）＞ 雄筆順網站選單。有生字表時以生字表為準，直接寫 lessons.tsv（見「其他情境」），課名優先用表上的，沒有才查教育百科、再沒有就問老師。照片或掃描檔辨識出來的字，先列給老師核對再抓圖。

老師很在意**同一種格子大小一致、表格對齊**。範本 `assets/template18.docx`（18 格）與 `assets/template21.docx`（21 格）的格線已經統一好，產生時只換內容、不動格線，所以不要用 Word 手動調表格。

## 流程

所有腳本在本 skill 的 `scripts/`。工作檔（lessons.tsv、生字圖）放在暫存/草稿資料夾，成品放老師指定的位置；沒指定就用 `Desktop\國五\五下字詞單` 這種「年級＋學期＋字詞單」的資料夾，與現有的 `Desktop\國五\五上字詞單` 並排。

### 1. 取得各課生字與課名

```bash
node scripts/fetch_lessons.js 114 康軒 5下 lessons.tsv
```

- 生字來自雄筆順網站（gsyan888.blogspot.com/p/stroke.html）的各課生字選單；課名來自教育百科生字詞彙表。
- 輸出 `lessons.tsv`：`L01<TAB>課名<TAB>生字`，並在畫面列出每課字數。
- 如果網站還沒有老師要的學年，腳本會列出現有的學年，請老師決定要用哪一年的版本先做（老師曾說「先用 114 下做，若 115 有變動再改」）。
- 課名缺的話（教育百科還沒上架），先問老師，或空著讓老師自己補。

### 2. 核對生字（重要）

雄筆順網站偶爾有錯字（例：114 康軒 5下 L06 網站寫「賭」，課本是「睹」）。所以：

- 老師有給官方生字表（例如 `國小國語5下生字表.doc`）→ 用 Word COM 讀出文字，逐字比對 lessons.tsv。官方表常是直排、課次倒序（十二…一），把各課生字串反序串接後比對最方便。以官方表為準修正 lessons.tsv。
- 沒有官方表 → 把教育百科與雄筆順不一致的字列給老師確認。

修正 lessons.tsv 之後再進行下一步，因為圖檔是依字擷取的。

### 3. 擷取彩色部件圖

```bash
node scripts/capture_chars.js lessons.tsv <圖片資料夾> [L03 L07 …只做某幾課]
```

- 用本機 Edge headless 開雄筆順（`html5_stroke_parts.html?words=字`），按「開始下載」後，把白底格線 canvas 與彩色筆畫 canvas 合成 465×465 PNG，檔名 `L01_01_簽.png`。
- 一個字約 4–5 秒，整冊（約 220 字）約 15–20 分鐘，請在背景執行並告訴老師大概要等多久。
- 已存在的圖會略過；有 FAIL 就再跑一次同一指令補抓。
- 內建瀏覽器面板連不到 localhost、也沒辦法大量存檔，所以一定用這支腳本（本機 Edge），不要改用瀏覽器面板截圖。

抓完先打開一兩張圖看看（應該是白底、淡粉紅格線、彩色部件的字）。

### 4. 產生 Word 檔

```powershell
& scripts/build_docx.ps1 -Lessons lessons.tsv -ImgDir <圖片資料夾> -OutDir "$env:USERPROFILE\Desktop\國五\五下字詞單" -Pdf
```

- ≤18 字用 18 格範本，19–21 字用 21 格範本；沒用到的格子放白色空白圖（保留空框給老師彈性使用）。超過 21 字會略過並警告，請跟老師討論要拆成兩份還是另做範本。
- 檔名沿用老師習慣：`字詞01.docx … 字詞09.docx、字詞010.docx … 字詞012.docx`。
- 腳本會回報每個檔的頁數與標題欄行數；標題欄任何一格超過 1 行代表課名太長，要處理（可略縮課名或與老師討論）。
- 寫入前先確認輸出資料夾裡沒有同名檔正在 Word 開著（有 `~$字詞NN.docx` 暫存檔就是開著），要覆蓋既有檔案前先問老師或先備份。

### 5. 檢查並回報

- 至少打開一課的 PDF（字數最少的一課最容易出問題）確認：標題欄一行、生字圖正確、空格是白的、格線對齊。
- 回報：輸出位置、各課課名與字數表、資料來源連結、需要老師確認的字、空格較多的課（例如只有 15 字的課最後一整排是空的）。

## 其他情境

- **只做某幾課**：fetch 仍抓整冊，capture/build 加上課次參數（`L03 L07` / `-Only L03,L07`）。
- **老師直接給生字**（沒有網站資料，例如自編補充字）：自己寫 lessons.tsv（`L01<TAB>課名<TAB>生字`），從步驟 3 開始。
- **改範本版面**：範本是 docx，表格格線是直接改 `word/document.xml` 的 tblGrid 統一的（有垂直合併的儲存格，用 Word COM 調寬度會把表格弄壞）。要改版面前先跟老師確認，改完同步更新兩個範本。範本不要用 Word 開啟後另存：Word 會重新整理圖片關聯，`fill_template.js` 就找不到生字圖的位置（會報「範本只有 N 格」）；要改就解壓、改 XML、再用 `scripts/repack.ps1` 打包。
- **字型/顏色**：彩色部件的配色來自雄筆順網站，不要自行重繪，老師的教學就是「跟著顏色分部件」。

## 需要的環境

Windows、Microsoft Word（檢查與輸出 PDF）、Microsoft Edge、Node.js 18 以上（內建 fetch/WebSocket）。
