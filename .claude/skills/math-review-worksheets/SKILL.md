# 資源班數學複習單

給資源班學生的數學複習教材。內容依出版社（目前是南一）的課本範圍與八格活動單出題，**題目數字自己重新出**（不照抄），每一題都用程式驗算。程式在本 skill 的 `scripts/`；第一次做好的完整範例（四上南一、期中考、第 1～5 單元）在 `examples/4上南一期中/`，新的一冊照著它改最快。

## 開始前先問老師（不要自己猜）

1. 年級、版本、考試範圍（到第幾單元）、到考試前還有幾次上課。
2. 一次上課多久（一節 40 分鐘 → 課堂單 3 頁）。
3. 有沒有複習考？排在哪裡？要不要做資源班版考卷？各考哪幾個單元？
4. 學生九九乘法熟不熟（不熟就在乘除法單子上附九九表）。
5. 教材放哪裡（例：`Desktop\南一教學資源\115上\國小\數學\4年級\卷類資源\八格活動單\學用`）、成品要放哪裡（四上期中是 `Desktop\學數4上\期中複習\`）。

## 老師定下的規則（一定要照）

- **課堂單**：一節 40 分鐘 → **3 頁**，一頁一個主題，標題「① ② ③」。每個主題：★小提醒框（規則、步驟）→ **老師示範（藍字已填好）** → **換你試試** → 自己做。多步驟題拆成「第 1 步、第 2 步……」。
- **作業**：**單面一頁，而且要整面寫滿，不能半面空白**（`fill.ps1` 量到 88% 以上才算）。前半是本次的**類題（數字和課堂單不一樣）**，後半「★ 複習一下」放前幾次的舊題目，讓考前的單元一直被複習到。
- **直式多的作業（乘法、除法）可以出雙面**（老師 2026-10-15：直式占版面，單面練習太少）：正反面都是本次類題，直式用 15 號字兩題並排（`side`，不會被切到兩頁），**不要強制換頁**，讓題目自然接到背面；「★ 複習一下」只放在背面最後，不要夾在中間。兩面都要寫滿。
- **作業的題目順序**（老師 2026-10-15 自己改過第 3 次作業定下的）：**心算（0 的秘密等）→ 直式計算 → 應用題 → ★ 複習一下**，同一類放在一起，不要穿插。
- **作業的應用題讓學生自己寫**：用 `free_app()`，只給「列式：」「直式：」的空白和靠右的「答：＿＿＿＿」；**不印算式框、不印直式格、答後面不印單位**（單位學生自己寫）。課堂單的應用題才用有鷹架的框（示範、算式框）。
- **複習考**：資源班版，保留工具（位值表、直式格、倍數表）但不放老師示範；題目和課堂單、作業都不重複；一份 3 頁。
- **答案**：學生卷不放答案；另做一份 `00_上課規劃與答案_老師用`（排程表＋每份的答案）。
- 版面：14 號標楷體（作業 13 號）、空格要大（數字用「（　　　　　　）」）、一行放不下就拆成兩行，**不要讓括號被擠到下一行**。
- 角度、三角形的圖是**實際尺寸**：提醒老師列印選「實際大小／100%」，學生才能用量角器量對。
- 成品、出版社教材內容都**不上傳 GitHub**（著作權），只放老師電腦。

## 做法

1. **讀範圍內每一小節的八格活動單（學用 PDF）**：列出每節的題型（例：1-1 往回數、跨千萬；3-5 旋轉角名稱；5-2 畫正三角形）。複習進度要把每一種題型都排到，最後再對一次有沒有漏。
2. **排進度表先給老師確認**：每次上課的範圍和重點、複習考位置。小節多的單元（如角度 6 小節）要多給時間；考前最後一次可排總複習（第 1～N 單元各出幾題、新數字）。老師改進度就照改（四上期中：第 1 單元只排 2 次、空出的一次當總複習）。
3. **寫內容**：複製 `examples/4上南一期中/`，照範例的寫法改題目。每份一個函式（`sXX` 課堂單、`hXX` 作業、`eXX` 複習考），`build.py` 的 `JOBS` 決定檔名和順序。
   - 每題用 `check(...)`／`cd(被除數, 除數, 商, 餘數)` 驗算，`ans(...)` 記答案（會自動進老師用答案檔）。
   - 作業補題寫在 `s_x.py` 的 `EXTRA`（存檔前自動加在最後），方便調整到整面。
4. **產生**（`<skill>` 換成本 skill 的路徑；Python 用 `C:\Users\class\AppData\Local\Programs\Python\Python312\python.exe`）：
   ```powershell
   python <範例資料夾>\build.py "C:\Users\class\Desktop\學數4上\期中複習"
   python <範例資料夾>\make_answers.py "C:\Users\class\Desktop\學數4上\期中複習\00_上課規劃與答案_老師用.docx"
   & <skill>\scripts\topdf.ps1 -dir "<成品資料夾>"            # 轉 PDF、印頁數
   & <skill>\scripts\fill.ps1 -dir "<成品資料夾>" -filter "*作業*.docx"   # 作業有沒有整面
   ```
   `build.py` 後面加 key（例：`h04 s07`）只做那幾份。
5. **檢查**：課堂單 3 頁、作業 1 頁且 ≥88%、考卷 3 頁；**打開 PDF 看**：括號沒有斷行、直式格數字沒被切到、圖的標號都在、量角器讀數和答案一致。
6. **回報老師**：資料夾位置、排程表、補了哪些漏掉的題型、哪些題目是新出的、列印要選 100%。

## 工具（詳細用法見 `references/tools.md`）

`lib.py`：`begin` 開新文件、`title` 標題＋座號姓名、`hint` 小提醒框、`para`／`q`／`step` 文字與題號、`place_table` 位值表（藍＝萬那節、黃＝個那節、橘＝要變的格）、`vgrid` 直式格（進位小格、第 2 列灰底 0）、`ldiv` 除法直式、`mults` 倍數表、`blocks` 積木、`boxes` 數字卡空格、`side` 兩題並排、`grid` 圖文排版、`image` 插圖。
`figs.py`（實際尺寸 PNG）：`angle` 角、`protractor` 量角器讀數圖（外圈 0 在左、內圈 0 在右）、`clock` 時鐘旋轉、`rays` 角度計算圖（直角記號、扇形、標字）、`tri` 三角形（等邊記號、直角）、`baseline` 畫角用底線。

## 踩過的坑

- 內容模組要寫 `lib.doc`，不能直接用 `doc`（`from lib import *` 匯入時 doc 還是 None）。
- 直式格字 18 號時列高是「至少」，設矮沒用；要省空間就用 `size=14/15`（會自動改固定列高；被除數那列維持自動，不會被切掉）。
- PowerShell 5.1 讀中文 `.ps1` 要 UTF-8 **有 BOM**；`-Filter` 不支援 `[]`，而且要寫 `*.docx` 不然會抓到 PDF。
- Word 開著檔案（資料夾有 `~$` 開頭的檔）時不要覆蓋，先請老師關掉。
- **在老師原有的考卷後面加頁**（例：`題目卷_2-1~2-2` 加第二面找錯題）：`.doc` 先用 Word 另存 `.docx`，`lib.doc = Document(那個 docx)`，`add_section(NEW_PAGE)` 後把欄數改成 1，**並移除新一節的 `w:docGrid`**（原考卷常開「文件格線」，會把直式格的行撐高、數字被切掉）。另存新檔，原檔不動。
- **找錯、改錯題**（老師 2026-10-15 要的）：每題左邊「小明的算法」（含進位小格、故意算錯），右邊同樣的空白直式格寫正確算法，下面勾「錯在：九九算錯／忘記加進位／第 2 列沒往左一格／加錯」；4 題裡放 1 題**算對的**，讓學生練判斷。
- 範例裡 `s_a.py` 的 `s01～s03、h02、h03` 和 `s_x.py` 的 `h01、x_h02、x_h03` 是改排程前的舊版，`JOBS` 沒用到（留著當題目參考）。

## 需要的東西

Word（轉 PDF、算頁數）、Python 3.12＋`pip install python-docx pillow`、標楷體（`kaiu.ttf`，Windows 內建）。
