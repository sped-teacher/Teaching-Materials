# 全抽組國語作業

給「全抽組」（國語課全部在資源班上）學生的回家作業。上課用平板網站，回家寫紙本。程式在本 skill 的 `scripts/`，每一課的補充資料放在網站資料夾 `<網站>/tools/worksheet/wsdata/XX.json`（隨 repo 同步）。

## 學生與老師定下的規則（一定要照）

- 學生**寫不出完整句子、一直問字怎麼寫** → 紙本每一題都要有可以照抄的字（詞庫、詞卡、選項）；**不出自己造句**（造句只在上課用平板做）。
- **不標注音**（要學會認字）。例外：形近字每組上面的目標字標注音、多音字的注音選項、第 ③ 頁段落大意整頁有注音。
- **語詞不用練**（學生有語詞簿）；不做答案卷。
- 彩色列印、**圖片低彩度**省墨水（程式已處理）；A4 直式；**每課 3 頁**。
- 寫字處用**底線**，不用格子。
- 標題：第一行淡色小字「第X課　課名」，第二行「① 主題」，全部靠左；座號姓名在右。

## 三頁內容

| 頁 | 內容 | 資料來源 |
|---|---|---|
| ① 形近字・多音字（一頁） | 每組目標字（標注音）→「先圈出不一樣的地方」→ 句子底線寫字；多音字圈注音 | 網站 `families`、`lookalikes`；補充題 `extraLook` |
| ② 短語短句・句型 | 短語：看情境圖，從**打亂順序**的彩色詞庫選詞，寫在同顏色底線上。句型：**每個句型 1 題**句子重組（看圖 → 詞卡前寫 1、2、3 → 抄整句） | `phrases`（scenes、bank 顏色）、`sentences[].combine.look`（看圖造句的句子和圖）；`flex` 挑戰句型不出 |
| ③ 段落大意 | 8 張圖標 A～H、詞庫（「詞庫：」自己一行），依課文地圖分段的大意，**固定 8 個空格**寫語詞 | `wsdata/XX.json` 的 `summary`（新寫的） |

**形近字、多音字要對照出版社〈字音字形〉**：〈字音字形〉的形近字要全部練到；網站某個字沒有題目，就在 `extraLook` 補一句。**多音字只練本課生字**——〈字音字形〉列的非生字多音（例：第二課「濟（人才濟濟）」）不出。

## 做一冊的流程

1. **先確認網站資料齊全**：要用的課 `mandarin/data/lessonXX.js` 有 families、lookalikes、phrases（有 blocks、scenes）、sentences（有 combine.look）、reading.map，圖都畫好了（`check_spec.mjs` 沒有 ❌）。新的一冊先用 `mandarin-learning-site` skill 把網站做好。
2. **核對〈字音字形〉**：讀出版社的字音字形檔，逐課比對網站的 families：缺題目的字列出來、非生字的多音字排除。
3. **寫段落大意**（每課一個 `wsdata/XX.json`，格式見 `references/wsdata.md`）：
   - 讀課文（`tools/texts/lessonXX.txt`，只在老師電腦），照網站 `reading.map` 的分段改寫，句子短、學生懂。
   - 從本課語詞（`words`）挑**剛好 8 個**、有網站圖的，用〔 〕標成空格；8 個不夠就加一句帶出別的語詞（例：第十課「日暮的時候，也就是傍晚」）。
   - 寫完**先列給老師確認**（每課：分段標題＋大意＋8 個挖空語詞），老師說可以才產生。
4. **產生**（在 repo 根目錄）：
   ```bash
   python .claude/skills/fullpullout-worksheet/scripts/fit.py --site mandarin --out "C:\Users\class\Desktop\學國5上\全抽作業"
   ```
   後面加課次（`01 04`）只做那幾課。每課先用最豐富的版面，放不下 3 頁會自動減少情境圖、縮小圖。輸出 `第XX課_全抽作業.docx`＋`.pdf`。輸出資料夾不在 repo 裡；新一冊依老師習慣命名（例：`Desktop\學國5下\全抽作業`），沒指定就問。
5. **檢查**：
   - 每課都要 3 頁（fit.py 會印頁數）。
   - 程式列出「⚠ 注音字型沒有把握的字」→ 用 `zyfont.py` 的方法把那個字六種字型都畫出來看，確認後加進 `zyfont.py` 的 `OVERRIDE`。
   - 第 ③ 頁的多音字讀音：程式用網站的點讀讀音規則（make_reader.py、`tools/texts/fixes.json`）；人名、特殊讀音不對時，在該課 `wsdata` 加 `zyfix`（例：`"背牠": "ㄅㄟ ㄊㄚ"`）。
   - 抽幾課打開 PDF 看：底線沒有斷行、詞庫沒有一個詞拆兩行、圖都有出現。
6. **回報老師**：檔案位置、每課頁數、新寫和新補的內容。提醒：在別台電腦改 Word 要裝「文鼎標楷注音」字型（PDF 不受影響）。

## 老師在 Word 裡怎麼改

- 文字直接改；底線是半形「_」，加減長度即可。
- 第 ③ 頁注音用「文鼎標楷注音」字型（字＋注音一起顯示）；注音不對時把那個字的字型換成「文鼎標楷注音破音一／二…」。
- 改完「另存新檔 → PDF」。

## 需要的東西

Word（轉 PDF、算頁數）、`pip install python-docx pywin32 pillow`、文鼎標楷注音字型（`kai08mz.ttc`）、網站的讀音資料（`python mandarin/tools/fetch_tables.py`）與 jieba、opencc（make_reader.py 用）。
