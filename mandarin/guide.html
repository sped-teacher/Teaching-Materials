📘 老師使用說明

這頁是寫給老師的（學生不用看）。先看「30 秒看懂」，其他需要時再跳過去看。

⏱️ 30 秒看懂

  • 這是什麼：康軒國語五上第 1～12 課的 iPad 練習，生字、語詞、句型、課文、形近字、成語都有。
  • 給誰用：資源班學生，一人一台 iPad；分等級 1～3，同一課可以依程度給不同支持。
  • 不是什麼：不是考試系統，也不是線上班級——不用登入、不上傳，紀錄只在那台 iPad 上。

老師只要記得 3 件事：

  1. 每台 iPad 開學設一次等級（按住右上角 ⚙️ 2 秒）。
  2. 學生照順序做：🎯 本課先完成 → 🌟 加練挑戰 → 🔁 錯題複習 → 📝 單課小考。
  3. 下課前花 3 分鐘批改造句、看小考成績（也在 ⚙️ 裡）。
✅ 開學前一次搞定第一次用看這裡 🎚️ 等級怎麼選先 2，再升降 🗺️ 一課怎麼帶每天上課的流程 🛠️ 出問題怎麼辦症狀 → 檢查 📋 各站速查目的、卡關、介入句 ✍️ 造句批改每天 3 分鐘 📊 成績怎麼看寫 IEP 用 📱 設備與隱私紀錄存在哪裡
第 1 部分・照著做

✅ 開學前一次搞定↑ 回上面

每台學生 iPad 做一次，約 3 分鐘。

  1. 加到主畫面
    按哪裡
    用 Safari 打開網址 → 上方「分享」⬆️ →「加入主畫面」。
    會看到
    主畫面多一個圖示，之後學生點它就好，不用再打網址。
    卡住
    找不到「加入主畫面」：分享選單往下滑；用 Chrome 開的話改用 Safari。
  2. 打開老師設定
    按哪裡
    按住右上角 ⚙️ 2 秒（圓圈跑滿）→ 回答乘法題。
    會看到
    「⚙️ 老師設定」視窗。
    卡住
    只點一下會跳「請按住 2 秒」，這是故意的（防學生誤開）。
  3. 設等級初值
    按哪裡
    「學習等級」選一個；不確定就選 2（預設就是 2）。
    會看到
    選到的等級反白。之後怎麼調，看 等級怎麼選。
    順便
    注音、自動念題目、音效、朗讀速度、「核心活動依序解鎖」也在這裡，可以先不動。
  4. 輸入教室密碼
    按哪裡
    按「完成」→ 隨便點一課 →「📖 課文點讀」→ 輸入教室密碼。
    會看到
    課文出現。這台 iPad 會記住，之後不用再輸入。
    注意
    密碼由老師輸入，不要告訴學生、不要寫在 iPad 上。
  5. 試一下聲音和麥克風
    按哪裡
    點任何 🔊；再到「句型練習」最後一步按 🎤 說一句話。
    卡住
    沒聲音、🎤 不能用 → 看 出問題怎麼辦。

🗺️ 一課怎麼帶↑ 回上面

🎯 本課先完成→🌟 加練挑戰→🔁 錯題複習→📝 單課小考
階段什麼時候老師可以說
🎯 本課先完成新課的前幾節。5 站：生字 → 語詞 → 短語短句 → 句型 → 讀懂課文。「今天先做到有⭐的地方就好，不會就按 💡。」
🌟 加練挑戰🎯 做完、或程度好的學生先做。形近字、成語是定期評量會考的。「形近字長得很像，先看字族文再選。」
🔁 錯題複習每節開頭先做（首頁、本課頁有提醒才需要）。「先把昨天錯的救回來，再做新的。」
📝 單課小考🎯 都做完、或定期評量前。沒有提示。「這次沒有 💡，錯了沒關係，會放進錯題複習。」

每節課 5 分鐘腳本

  1. 開始（1 分）：學生點主畫面圖示 → 有 🔁 提醒就先做錯題複習。
  2. 中間：做本課的站。老師巡視時看「卡關訊號」（各站速查）。
  3. 結束前（3 分）：按住 ⚙️ →「✍️ 學生造的句子」批改（怎麼批改）。
  4. 每週一次：看「📝 單課小考成績」的「要加強」，下週先補那一站。

🛠️ 出問題怎麼辦↑ 回上面

點症狀打開，由上往下一項一項檢查。

🔇 沒有聲音

先分辨是哪一種沒聲音：

  1. 全部都沒聲音（🔊、答對的音效都沒有）→ iPad 音量調大、側邊靜音／控制中心的鈴鐺關掉；藍牙耳機是不是連到別的地方。
  2. 剛打開時按 🔊 沒聲音，後來又好了 → iPad 規定要先點過畫面才能發聲；先點一下畫面再按 🔊。
  3. 音效有、🔊 念字沒聲音或念得怪 → iPad「設定 → 輔助使用 → 朗讀內容 → 聲音 → 中文（台灣）」下載一個聲音。
  4. 🔊 有、答對答錯沒有音效 → 老師設定「音效」被關掉了。
  5. 題目沒有自動念 → 不是壞掉：等級 2、3 預設要點 🔊 才念；要自動念就在老師設定開「自動念題目」。
🎤 不能用／朗讀挑戰沒反應
  1. 有沒有連網路？語音辨識要上網。
  2. iPad「設定 → Safari → 麥克風」改成「允許」（或「詢問」，跳出來時按允許）。
  3. 用 Safari 或主畫面圖示打開（Firefox 不能用）。
  4. 還是不行 → 改用鍵盤上的 🎤（要開「設定 → 一般 → 鍵盤 → 啟用聽寫」），或直接打字。
  5. 朗讀分數怪怪的：辨識器會猜成通順的詞，細微聲調抓不到，分數只供參考。
🆕 看不到新版
  1. 網站更新後最多約 10 分鐘才會生效。
  2. 把主畫面的 App 完全關掉（從下往上滑、把它滑掉）再打開。
🗂️ 紀錄、星星不見了
  1. 是不是換了一台 iPad？紀錄不會跟著學生走，只在原來那台。
  2. 是不是用 Safari 開，而不是主畫面圖示（或反過來）？兩邊的紀錄可能分開。
  3. 是不是用了私密瀏覽，或有人清除了 Safari 的網站資料？清掉就找不回來。
🔑 課文點讀沒有鎖／要重新鎖／忘記密碼
  1. 輸入過密碼的 iPad 會記住，所以看起來「沒鎖」是正常的。
  2. 要重鎖：老師設定 →「🔒 鎖上課文」。
  3. 忘記密碼：請設定網站的老師提供，密碼不會寫在任何地方。
⚙️ 打不開老師設定
  1. 要按住不放 2 秒，手指不要移動；只點一下不會開。
  2. 乘法題答錯會清空，再算一次就好。
第 2 部分・速查（可以列印）

🎚️ 等級怎麼選↑ 回上面

先全部設等級 2，做完 2～3 組再看下面調整。改等級只要按住 ⚙️ 換一下，之前的紀錄不會不見。

⬇️ 降到 1

一直按 💡、亂點、答錯就生氣或哭；或獨立答對常低於 5 成；或看不懂題目。

➡️ 留在 2

偶爾用 💡、星星多半 2 顆；獨立答對約 5～8 成。

⬆️ 升到 3

幾乎不用 💡、自己一直往下點；星星多半 3 顆，獨立答對 8 成以上。
例：小明等級 2，認識生字連兩組 3 顆星、都沒按 💡 → 升等級 3。
小華等級 2，每題都先按 💡、語詞獨立答對 40% → 降等級 1，兩週後再看。

「獨立答對」在 ⚙️ →「📊 學習紀錄」裡看，見 成績怎麼看。可以只換單一學生，也可以某一課先降、做熟了再升。

📋 各站速查↑ 回上面

🎯 本課先完成
✏️ 認識生字
字卡→聽音選字→找部首		認得字形、讀音、部首聽音選字一直猜；部首選成聲旁「先看左邊（上面）是什麼部件，它跟意思有關。」
🧩 學會語詞
詞卡→配對→看意思選語詞		語詞的意思和用法配對很快但亂點；看意思選不出來「先點圖卡聽一次，想想你什麼時候會用這個詞。」
🔗 短語短句
認識結構→排一排→選出對的		詞語怎麼組成短句排序只排對前半；每次都同一個位置錯「先找『誰』，再找『做什麼』。」
🧱 句型練習
認識→排句子→選後半句→選連接詞→自己造句		學會本課句型的連接詞和意思關係連接詞選錯（意思相反）；造句格子空白很久「前面說了什麼？後面是相反、還是接著做？」造句卡住：「先說給我聽，再按 🎤。」
📖 讀懂課文
事件排順序→回答問題		抓課文大意和順序排順序靠猜；問題答案都選最長的「打開課文點讀，找找看這件事在第幾段。」
🌟 加練挑戰
🔍 形近字
字族文→看語詞選字→組字→句子選字		分辨長得像的字（評量常考）、多音字同一組字一直選反「這兩個字哪裡不一樣？那個部件是什麼意思？」
🏮 生字變成語
成語卡→補字→選成語→配對		本課生字的延伸成語（評量常考）補字選同音字；意思和成語對不起來「看圖卡，故事是在說什麼？」
🕵️ 修辭小偵探
認識修辭→有沒有用→比成什麼		認出譬喻等修辭看到「像」就說有譬喻「兩樣東西真的有像嗎？哪一樣被比成哪一樣？」
🎧 注音聽打
聽語詞→點注音鍵盤→選字		注音拼讀、聲調、同音字選字聲調一直錯；選字選同音的別字「念慢一點，手跟著打拍子數聲調。」
👂 聽聽看
聽一句話→回答問題		聽覺理解（綜合）一直重聽也答不出來「聽到『誰、在哪裡、做什麼』就記下來。」
其他
🔁 錯題複習間隔複習答錯的題目、重寫老師打 ✗ 的造句同一題一直回來那一題老師直接一對一講解。
📝 單課小考各站抽題、沒有提示，看真正學會多少分數低的站回去做那一站，等級可先降一級。
📖 課文點讀點字、詞、句就念（要教室密碼）
🎙️ 朗讀挑戰一段一段念，iPad 比對讀音打分數一直 0 分（多半是 🎤 問題）看 🎤 不能用。

注音開關：關掉會藏語詞卡、成語卡、形近字卡、課文點讀、朗讀挑戰的注音；生字卡、多音字、注音題、注音聽打的答案一定顯示。

✍️ 造句批改（每天 3 分鐘）↑ 回上面

學生那邊發生什麼：句型練習最後一步「自己造句」→ 電腦只檢查結構（連接詞、順序、每段有沒有寫、有沒有照抄例句）→ 通過後補標點、念一遍 → 學生自己判斷「通順嗎？」→ 按「👍 通順，送給老師」→ 畫面顯示「已經送出，等老師批改」。

電腦看不懂意思：「雖然哈哈，卻哈哈啊啊」結構對也會送出，所以一定要老師批改。
  1. 打開
    按哪裡
    按住 ⚙️ 2 秒 → 最上面「✍️ 學生造的句子（○ 句待批改）」。
  2. 看一句、按一個
    ✓
    意思通順，結束。
    ✗
    要重寫。學生下次打開「🔁 錯題複習」會先看到這句，用同一個句型重寫；重寫完變「已重寫」，新句子也會出現在列表裡等批改。
    ✏️
    老師在旁邊時直接改字 → 儲存（算通過，原句會留著）→ 按 🔊 念給學生聽。
  3. 順便看小字
    會看到
    「自己改了 ○ 次」「結構試了 ○ 次」——改過的次數多代表學生有在自我檢查；結構一直試不過，表示句型還不熟，回到前面的步驟。

等級 1、2 是填空句框，「先……再……」「一邊……一邊……」「時而」「不但（沒）」「不僅」的句框會多一格「誰？」，要先寫主詞。

📊 成績怎麼看（寫 IEP 用）↑ 回上面

都在 ⚙️ 老師設定裡，要在學生自己的 iPad 上看。

看什麼在哪裡怎麼算
小考分數📝 單課小考成績答對題數 ÷ 總題數（沒有提示，錯一次就算錯）。每課留最近 3 次，括號是當時的等級。
要加強的站📝 單課小考成績最近一次小考中，答對不到 6 成的練習站。
錯題練習中📝 單課小考成績還沒學會的錯題數。錯題照 當天 → 1 天 → 3 天 → 7 天 再出現，連續答對 4 次就學會、移除；答錯回到當天。
獨立答對📊 學習紀錄 → 點開一課沒用 💡、第一次就答對的比例（各組平均）。最能看出「自己會」的程度。
星星📊 學習紀錄每組依獨立答對：9 成以上 3 顆、6 成以上 2 顆、完成就 1 顆；留最高的。
朗讀分數📊 學習紀錄 → 🎙️ 朗讀挑戰每個字念對 1 分、聲調不對 0.5 分、沒念到 0 分；每段留最高分再平均。語音辨識有誤差，只供參考。
造句✍️ 學生造的句子老師 ✓／✗ 的結果、自己改了幾次、結構試了幾次。

IEP 可以這樣寫（照抄改數字）

・在第 4 課單課小考（等級 2，12 題，無提示）得 75 分；「形近字」答對不到 6 成，列為下階段加強重點。
・「認識生字」獨立答對率（未使用提示、第一次即答對）由第 1 課 55% 提升至第 4 課 85%，已由等級 2 調升為等級 3。
・能使用「雖然……卻……」句框自行造句，10 句中 8 句經教師批改意思通順，2 句經提示後能自行修改。
・課文朗讀（語音辨識參考）平均 82 分，聲調錯誤集中於三聲。

📱 設備與隱私↑ 回上面

  • 一台 iPad ＝ 一個學生的紀錄。不用登入，資料不上傳、不離開那台 iPad，網站也不收集個人資料。
  • 換 iPad、清除 Safari 網站資料、用私密瀏覽 → 紀錄看不到也救不回來。學生共用 iPad 的話紀錄會混在一起。
  • 設定（等級、注音等）也是每台各自的，可以每個學生不一樣。
  • 學期末要重來：⚙️ 最下面「清除這台 iPad 的學習紀錄」（會清掉錯題、小考、造句，無法復原，先抄下要的成績）。
  • 教室密碼只給班上使用，課文全文有著作權。
